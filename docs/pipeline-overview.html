Pipeline tổng quan

Luồng dữ liệu từ lúc thu thập tin ngành building automation đến khi ra digest — gồm 2 track song song (Registry Diff, News Pipeline) và 2 đường bypass thời gian thực không qua LLM/batch.

Luồng chính (batch/digest)
Bypass LLM/batch — alert, <1 phút
Feedback loop
AI Xử lý bằng Haiku 4.5 (tốn token)

Chi tiết từng bước

Bước Xử lý bởi Input Output
Extract news-extractor (trafilatura) 1 URL title, author, published_at, lang, canonical_url, body_text, word_count
Dedupe Code logic (canonical URL → SimHash) canonical_url, body_text Match / không match với bài đã có
Triage Haiku 4.5 · Batch API title + 1200 từ đầu + tên nguồn verdict, topics, brands, content_type, confidence
Event clustering Haiku 4.5 · 1 call/ngày {article_id, title, source, first_seen_at} × 72h article_ids[], title_canonical
Deep analysis Haiku 4.5 · Messages API realtime 2-3 bài đại diện của 1 event summary_vi, why_it_matters, recommended_action[]
Ranking Code logic (rank_score) Mọi event trong ngày + kết quả LLM Top 5 event đã sắp hạng
Delivery n8n → Zalo KHub / Telegram Top 5 event + nội dung deep analysis news.digests (payload jsonb)
Feedback Người dùng bấm rating trên Zalo Digest đã gửi news.feedback (rating -1/0/1/2)

Cập nhật vận hành gần nhất

§13 "Dev nội bộ" phụ trách Track A + B chưa map vào ai trong 5 nhân sự — cần chốt trước khi commit timeline.
§10 Đề xuất chạy digest thô (bỏ SimHash tầng 2 + event clustering) song song Track A ở tuần 1-2, để test sớm giả thuyết rủi ro lớn nhất: "digest bị bỏ đọc".
